## Ограничения

UTC и начало интервала для CSV пока остаются явно указанными допущениями.
Погода подтверждена на отдельных запусках, полного архива всех дат локально нет.
Для февраля в исходных CSV нет факта. Q10/Q90 остаются null до накопления
достаточной истории ошибок. Широкая оценка качества ML и подбор победителя
не заменяются синтетическими метриками.

CI настроен на Windows и Linux, но предыдущий серверный запуск GitHub Actions
был остановлен до выполнения шагов из-за billing-блокировки аккаунта организации.
Локальная проверка не является подтверждением выполнения Linux-job на GitHub.
